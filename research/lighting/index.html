Scan preprocessing experiments

Before OCR, the 1938 directory scans get an in-house cleanup pass: uneven lighting is evened out by estimating the page's illumination field and dividing it out, instead of re-shooting the pages. Each experiment below is one algorithm applied to the same scan. Algorithms are scored by character error rate against reference transcripts — first with local Tesseract, then a small Gemini trial for the winner.
